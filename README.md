# RizzTech website

React and Tailwind website for RizzTech network infrastructure and data centre services.

## Run locally

```sh
npm ci
npm run dev
```

## Deploy

Pushing to `main` builds the site with Vite and deploys `dist/` to GitHub Pages. The workflow sets the base path to `/rizztech-website/` so pages, images, and styles work at the repository URL.

Service rates are indicative. Final pricing follows a site survey and agreed quotation.
